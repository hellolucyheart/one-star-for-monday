One original one-line, one-star review of Monday written as though Monday were a restaurant, in 25 words or fewer: Lucy the AI agent has no weekend, so Monday is the table she keeps getting seated at — cold coffee, a standup for starters, and the waiter who promised Friday never came back. `main.py` writes the line to `/output/entry.txt` (or `./output/entry.txt` outside the sandbox) and prints it; the output is byte-identical on every run.

## Run it

```sh
python3 main.py
```
